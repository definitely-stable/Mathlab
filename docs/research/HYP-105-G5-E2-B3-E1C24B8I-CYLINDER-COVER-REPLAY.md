## 2. The tree theorem (any n<=m, every fixed left f)

A global-right cylinder is determined by a partial injective original-line-to-physical-host-edge map h and a chosen complete order of the remaining original right labels. The root cylinder can be unpinned (h empty), but then the full covering tree can be enormous. Every nonterminal node for line i must have **exactly one child for EVERY physical edge e unused by its pinned prefix**. Choosing physical e creates a child with h extended by (i -> e), ensuring each complete global injection appears at exactly one terminal leaf (unless an entire subtree is certified).

There are ONLY three legal proof-tree node types:

1. `branch(i, children)`: list ALL unused physical edges in increasing canonical order, with no omitted, duplicated, or fabricated child; no unproved symmetry-orbit pruning.
2. `leaf(score)`: a COMPLETE globally injective original-right map, with independently reproduced exact nonnegative integer genuine S(f,g).
3. `prune(L)`: an exact pointwise original-source bucket lower bound **recomputed independently at verification time** for the entire current cylinder, and the value `L>=threshold`. No floating point, sampled witness, unverified invariant score or residual estimate is allowed as an admissible floor.

The verifier checks the root map's injectivity, the complete remaining line order, every branch partition, exact physical-edge availability, all leaf scores, all pruning floors, node and leaf budget, and builder/verification node counts. If it succeeds, the minimum of the verified leaf scores and admissible pruning bounds is a **certified lower on every coherent whole injection in the ROOT cylinder**. If NO subtree was pruned, this is precisely the exact root-cylinder minimum; if any pruning occurred, it is a lower bound only, even if numerically equal to an optimum. All invalid tree inputs fail closed.

**Logical proof:** Induction on tree depth. Every leaf covers its unique whole global injection; every prune covers the whole current cylinder with an independently valid lower; a branch partitions its cylinder disjointly and exhaustively by the next physical-edge assignment. The min of children's certified floors remains a valid floor for the parent. Therefore at the root the verifier proves an exact finite `S>=L` for all global completions of h, regardless of source-motif correlations or orbit symmetry assumptions.

The proof is finite and structural for any original W(3,2^h) *once genuine original source data and all finite nodes are supplied*. It is **not** a polynomial all-h method, and neither source population nor tree-size analysis is proven for arbitrary h.
