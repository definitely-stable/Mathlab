`sigma_i * omega_i[slot] + sigma_j * omega_j[slot'] = 0 (mod5)`

on each of the 12 physical coordinate dual edges (i,j).

For a particular physical coordinate edge with two NONZERO GF5
coefficients x,y, there are exactly THREE exclusive possibilities:

- `x == y` implies `sigma_i == -sigma_j`
  (the two ORIGINAL column sign bits must have XOR 1).

  (sign-bit XOR 0).
- Neither relation implies **NO** sign assignment can cancel this

is odd; `x==(-x)` would imply 2x=0 and x=0, a contradiction.
