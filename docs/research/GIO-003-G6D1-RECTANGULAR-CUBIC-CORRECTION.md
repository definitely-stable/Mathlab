## Error and corrected proof

For a real simple (s,t)-biregular original source of girth at least eight, let B be its point-by-line incidence matrix, J the conforming all-ones matrices, h=s+t and F=J-BB^TB+hB the genuine 0/1 missing original threeflag projection matrix. Define
`Delta_L=|L|-(t+1)(st+1)` and `Delta_P=|P|-(s+1)(st+1)`. Then each **row** of F sums to Delta_L and each **column** to Delta_P. This type distinction was lost in the full-entry cubic coefficients in the original G6-D1 draft.

Set T=BB^T, U=B^TB. The independent exact source threewalk identity is `BB^TB-hB=J-F`. Squaring without dropping a rank-one term gives

```
T(T-hI)^2 = (J-F)(J-F)^T
          = FF^T + (|L|-2 Delta_L) J_PP.

U(U-hI)^2 = (J-F)^T(J-F)
          = F^TF + (|P|-2 Delta_P) J_LL.
```

The expansions are literal: `J F^T = F J^T = Delta_L J_PP`; dually `J^T F = F^T J = Delta_P J_LL`. The previous coefficients exchanged Delta_P and Delta_L. These full-matrix identities were *false* for asymmetric positive-excess sources, although the centered spectral consequences were valid.

On the orthogonal complement to all-ones, the J terms vanish. The correct centered consequences, `x(x-h)^2 <= Delta_L Delta_P`, the fixed O(r^(3/2)) excess gate, and the fixed centered-norm O(r^3) quadratic gate of G6-D2 are unaffected by this particular rank-one defect. The symmetric q-arc/Wenger cases of D2/D3 have `Delta_L=Delta_P` and likewise retain their original scope. This does **not** independently validate every subsequent HEAVY/LOW lemma.

## Genuine exact asymmetric falsifier

Take the literal original point-line incidence of actual GQ(2,4) as generated by the project's independent geometry module, and form two disjoint copies (no invented source projections). Each copy has 27 points, 45 lines. The doubled genuine source is simple, degree 5 on points and 3 on lines, girth eight, with 54 points, 90 lines, `Delta_L=45`, `Delta_P=27`, and real missing cross-component projections. Its principal BB^T eigenvalue is `(s+1)(t+1)=15`; h=6, so `15(15-6)^2=1215`. The corrected point-side RHS principal value is `45*27+(90-2*45)*54=1215`, but the *old* RHS is `45*27+(90-2*27)*54=3159`. Dual side also fails with the old coefficient. Repeating on two genuine GQ(4,2) copies provides the independently reversed typed orders.

The new test builds **actual original source flags**, reconstructs F via a separate source-flag-only threepath oracle, checks full matrix entry identities on both typed sides, verifies exact row/column sums, and checks the false old formula explicitly on the all-ones vector. Existing GQ(2,4) undoubled tests have `Delta_L=Delta_P=0`, and old doubled W(3,2) tests have `Delta_L=Delta_P=15`; thus neither could detect the swap.
