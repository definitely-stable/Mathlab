## 1. Математический фронтир и новое утверждение

Ранее #746 независимо доказал для любого исходного удаления Z точную формулу \(M_Z=12s^2|Z|-\Xi_Z\), а для полных звёзд **либо** точек, **либо** прямых — \(M_Z\le8s^2|Z|\) и радиус удалений в 3/2 раза выше. Обнаружен более общий определяющий параметр, который устраняет искусственное требование выбирать только один тип звёзд и даёт непрерывную шкалу для произвольных частичных удалений.

Пусть для всякого исходного неинцидентного (q,r) единственная **полная ORIGINAL GQ** проекция есть

\[
q\longrightarrow\ell\longrightarrow p\longrightarrow r
\]

с тремя различными named source-ID якорями

\[
a_1=(q,\ell),\quad a_2=(p,\ell),\quad a_3=(p,r).
\]

Их принадлежность любому adversarial \(Z\subseteq I\) обозначим \(b_i=1_{a_i\in Z}\).

Определим три точных **целочисленных** source-параметра:

\[
\begin{split}
D_Z&=\#\{(q,r):q\notin r,\ b_2=1,\ b_1=b_3=0\},\\
H_Z&=\#\{(q,r):q\notin r,\ b_1=b_2=b_3=1\},\\
F_Z&=\#\{(q,r):q\notin r,\ b_2=0,\ b_1=b_3=1\}.
\end{split}
\tag{MX-1}
\]

\(D_Z\) — изолированные удаления **среднего** якоря; \(H_Z\) — одновременное удаление всех трёх; \(F_Z\) — оба крайних удалены, средний сохранён. Для каждого исходного ID роль среднего якоря встречается ровно \(s^2\) раз, так что \(0\le D_Z\le s^2|Z|\).

### Лемма MX-EXACT — новая безусловная all-h identity

Для \(m=b_1+b_2+b_3\) имеется **точное побулево тождество**

\[
(m-1)_+
=b_2-b_2(1-b_1)(1-b_3)+b_1b_2b_3+(1-b_2)b_1b_3.
\tag{MX-2}
\]

Доказательство: при \(b_2=1\) обе стороны равны \(b_1+b_3\), при \(b_2=0\) обе равны \(b_1b_3\). Каждый исходный флаг появляется средним якорем ровно \(s^2\) раз по аксиоме настоящей GQ. Каждая настоящая неинцидентная (q,r) даёт ровно ЧЕТЫРЕ ориентированные физические off-coordinate пары концов, поскольку f(q) и g(r) — неупорядоченные 2-пары из отдельно глобально инъективных физических отображений. Поэтому

\[
\boxed{
\Xi_Z=4(s^2|Z|-D_Z+H_Z+F_Z),
\qquad
M_Z=8s^2|Z|+4D_Z-4H_Z-4F_Z.
}
\tag{MX-3}
\]

\(M_Z\) — ТОЧНОЕ число маскированных Z ориентированных физических конечных пар с действительной **полной** неинцидентной исходной проекцией (q,r), до исключения иных не-Z-плохих концов. Отсюда для ВСЯКОГО фиксированного \(f,g,Z\)

\[
\boxed{M_Z\le8s^2|Z|+4D_Z\le12s^2|Z|.}
\tag{MX-4}
\]

Это независимое точное all-h улучшение source-формулы, а не численная аппроксимация. Удаление ОДНОГО изолированного исходного ID достигает старой оценки в точности: \(D_Z=s^2|Z|,\ H_Z=F_Z=0,\ M_Z=12s^2|Z|\). Следовательно, **для всех произвольных Z нельзя ошибочно подставлять 8 вместо 12**; у этого запрета теперь имеется конкретный genuine-original контрпример и автоматический тест.

## 2. Новая теорема: смешанные объединения полных звёзд точек И прямых

Выбираем произвольно, включая adversarial выбор после f/g, \(P_0\subseteq P\), \(L_0\subseteq L\). Удаляем всё объединение их исходных source stars:

\[
\boxed{Z_{P_0,L_0}=\{(p,\ell)\in I:\ p\in P_0\ \lor\ \ell\in L_0\}.}
\tag{MX-5}
\]

Одна инцидентность, попавшая и в point-star, и в line-star, считается ОДИН раз. Точная мощность:

\[
|Z_{P_0,L_0}|=(s+1)(|P_0|+|L_0|)
-e_{\rm inc}(P_0,L_0).
\tag{MX-6}
\]

У каждой q--ell--p--r проекции исходные удаления выражаются:

\[
b_1=1_{q\in P_0\lor\ell\in L_0},\
b_2=1_{p\in P_0\lor\ell\in L_0},\
b_3=1_{p\in P_0\lor r\in L_0}.
\tag{MX-7}
\]

Если \(b_2=1\) из-за \(p\in P_0\), то третий якорь (p,r) тоже удалён. Если из-за \(\ell\in L_0\), то первый (q,ell) тоже удалён. Значит удалённый средний якорь **никогда не изолирован**; результат справедлив даже при пересечении звёзд:

\[
\boxed{D_{Z_{P_0,L_0}}=0,\quad
M_{Z_{P_0,L_0}}=8s^2|Z|-4H_Z-4F_Z\le8s^2|Z|.}
\tag{MX-8}
\]

Это безусловная универсальная source-GQ лемма для всех s, для любой корреляции f/g, для смешанных, множественных, пересекающихся point+line-stars; содержит оба старых результата #746 как частные случаи.

## 3. Непрерывная source-deletion устойчивость через \(\kappa\)

Один рациональный абсолютный \(0\le\kappa\le1\) выбираем ДО s,f,g,Z. Определим законный класс source deletion

\[
\mathcal Z_\kappa(s)=\{Z\subseteq I:D_Z\le\kappa s^2|Z|\}.
\tag{MX-9}
\]

Тогда (MX-4) обеспечивает \(\boxed{M_Z\le(8+4\kappa)s^2|Z|}\). Класс \(\kappa=0\) включает все смешанные полные point+line stars, но может включать и другие исходные Z без изолированных средних якорей. Класс \(\kappa=1\) включает совершенно ВСЕ Z; его bound оптимален для одиночного Z. Для \(0<\kappa<1\) получаем новую промежуточную гарантию.

Сохраняем исходные математические HEAVY/LOW/selector/source-inverse леммы из #744–746, а также доказанную опубликованную ordinary graph C6 supersaturation теорему Jiang–Yepremyan (2020), DOI https://doi.org/10.1017/S0963548320000206. Пусть \(C_0\ge\max(1,C_{\rm graph})\), \(0<c_0\le\min(1,c_{\rm graph})\) — фиксированные ДО s,f,g,Z **существующие** рациональные границы; опубликованные графовые константы экзистенциальны, не равны 1 по предположению. ФОРМАЛЬНЫЕ примеры (1,1),(2,1/5),(7/3,1/17) не являются подтверждёнными численными графовыми константами.

Определим, как в #744–746:

\[
\begin{gathered}
R=93313,\quad T=\lceil(17/2)R^3C_0^3\rceil,\quad
q_3=64\binom{195}{3},\quad L_6=24+153T^2,\\
L_4=q_2^2\lceil\sqrt{\lceil17L_6/4\rceil}\rceil+19T,\quad
B_0=\lceil\sqrt{360\cdot65\,T}\rceil,\\
E=5q_3\lceil\sqrt{L_6}\rceil,\quad
D=4\lceil\sqrt{B_0TL_4}\rceil,\\
s_0=\max\{64,444T,(8E)^2,(8D)^8\},\quad
\delta=c_0/R^6,\quad
t_\star=119/24-2(54162/53838)\delta.
\end{gathered}
\tag{MX-10}
\]

Старый arbitrary-Z бюджет \(\rho_1=t_\star^2/(12q_3^2L_6)\) заменяется для законного source класса \(\mathcal Z_\kappa\) на

\[
\boxed{
\rho_\kappa=
\frac{t_\star^2}{(8+4\kappa)q_3^2L_6}
=\frac3{2+\kappa}\rho_1.
}
\tag{MX-11}
\]

Радиус **строго** возрастает при уменьшении \(\kappa\), и \(\rho_0=3\rho_1/2\) — новый класс смешанных source stars. Для всех \(\kappa\) одновременно

\[
0<\rho_1\le\rho_\kappa\le\rho_0
<\frac{(119/24)^2}{8q_3^2\cdot24}<2^{-32}.
\]

Поэтому прежний HEAVY обычный граф БЕЗ клонирования с \(R=93313\) и LOW размер парного исходного ядра \(|C|\ge3s^4/4\) остаются корректными. Все константы T,L6,s0,δ одинаковы для всей шкалы κ. Применение Jensen к настоящим координатно proper P3 даёт для \(|Z|\le\rho_\kappa s^4\)

\[
\#\mathrm{masked}\le
\sqrt{M_Z\cdot q_3^2L_6s^6}
\le q_3\sqrt{(8+4\kappa)L_6\rho_\kappa}\,s^6
=t_\star s^6.
\tag{MX-12}
\]

Остальные три независимые non-Z-ошибки ≤s^6/8 каждая при том же s0; исходный Blakley–Roy W3 floor ≥16s^6/3. В HEAVY — ≥δs^6 настоящих оригинальных D6. В LOW с малым D6 — ≥(54162/53838)δs^6 **произведённых** настоящих BBo по прежней правильной односторонней P3→BBo 2-to-1 инверсии (без ложной сюръективности всего BBo). Отсюда кандидатная **условная на ранее названные все-h леммы** теорема:

\[
\boxed{
\forall s=2^h\ge s_0,\ \forall f,g,\ 
\forall Z\in\mathcal Z_\kappa(s),\ |Z|\le\rho_\kappa s^4:
\quad
S_s(f,g)\ge\frac{c_0}{93313^6}s^6,\quad
R_3(f,g)\ge\frac{54162c_0}{93313^6\,51^6}s^6.
}
\tag{MX-13}
\]

\(S_s\) — исходная сумма семи положительных классов шести разных named original incidence-ID. \(R_3\) — отдельная **аддитивная** сумма знаковых GF5 вероятностей, НЕ вероятность union. Не доказан новый общий ASET exponent.

| κ, класс допустимых удалений | Улучшение допустимой плотности Z к произвольному Z |
|---|---|
| 0 — D_Z=0; в частности любые смешанные полные point+line stars | 1.5× |
| 1/4 — не больше четверти изолированных средних source-якорей | 4/3× |
| 1/2 — не больше половины | 6/5× |
| 3/4 — не больше 3/4 | 12/11× |
| 1 — совершенно произвольное Z | 1× |

Это настоящая source-структурная устойчивость, не эффект от округления опубликованных graph C/c.

### 3.1. Более практичный ALL-h критерий: смешанные полные звёзды плюс произвольные дополнительные ID

Можно не вычислять D_Z по всем O(s⁶) исходным проекциям. Пусть \(Z_0\) — произвольное исходное СМЕШАННОЕ объединение полных звёзд точек и прямых (MX-5), а \(E\subseteq I\) — любое дополнительное, даже adversarial и зависящее от f/g множество именованных ORIGINAL флагов. Рассмотрим \(Z=Z_0\cup E\) и количество **фактически новых** удалённых флагов \(e=|E\setminus Z_0|\), не считая повторных original ID пересекающихся звёзд.

Если в какой-либо full GQ проекции удалён средний flag и оба крайних НЕ удалены, его средний flag **не мог принадлежать Z0**: иначе полнота удалённой point-/line-star заставила бы удалить один из крайних. Значит средний flag принадлежит \(E\setminus Z_0\). Каждая такая исходная инцидентность является средним якорем РОВНО s² разных неинцидентных GQ-проекций. Поэтому без предположений о распределении E, f/g или взаимной независимости:

\[
\boxed{D_Z\le s^2e=s^2|E\setminus Z_0|,\qquad
M_Z\le8s^2|Z|+4s^2e.}
\tag{MX-HYBRID}
\]

Если одна константа \(\eta\in[0,1]\), выбранная ДО s,f/g/Z, ограничивает долю добавочных флагов \(e/|Z|\le\eta\), то этот гибридный исходный класс **автоматически входит** в \(\mathcal Z_\eta(s)\), и при том же \(s_0,\delta,R\) допустимый бюджет равен \(\rho_\eta=3\rho_1/(2+\eta)\). Это более удобный source-структурный критерий, чем пересчёт всех GQ-проекций для каждого Z.

Конкретный independent original W(3,4) пример: одна полная point-star содержит 5 исходных флагов, к ней добавлен один иной именованный source ID; \(|Z|=6,e=1\). Структурный критерий даёт \(\eta=1/6\) и гарантирует \(18/13\) прежнего бюджета, а фактически пересчитанный source дефект составляет \(\kappa_{\rm eff}=1/8\), давая более сильную instance-specific оценку \(24/17\) прежнего бюджета. **Ни одна из этих конечных дробей не является универсальным all-Z улучшением**; это два безопасных критерия для заданных классов исходных удалений. В новом JSON сохранены e, \(\eta\), реальная \(\kappa_{\rm eff}\) и неравенство \(D_Z\le s^2e\) для каждого настоящего случая.
