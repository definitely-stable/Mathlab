## 1. Действительная задача

Для настоящей symplectic generalized quadrangle W(3,s), s=2^h, фиксированных отдельно глобально pair-injective и произвольно коррелированных отображений f(point),g(line), оригинальных именованных incidence-ID флагов и пар физических диагоналей каждого флага, рассматривается ORIGINAL источник с графом конфликтов J.

Для каждой пары упорядоченных физических концов u,v пусть Γ_uv состоит из всех координатно-правильных ориентированных физических путей длины 3. Каждый путь γ имеет три попарно J-неконфликтующих настоящих ORIGINAL-владельца и строго положительную вероятность p_γ сохранения при ОДНОМ общем равномерном порядке приоритетов ORIGINAL-флагов и ДВУХ общих независимых бинарных раскрасках физических координат. Независимость различных путей не предполагается.

Определим

\[
M=\sum_{u,v}\bigl(\sum_{\gamma\in\Gamma_{uv}}p_\gamma\bigr)^2,\qquad G=M-B.
\]

Здесь B — точная сумма p_γp_η по упорядоченным несовместимым парам с одинаковыми концами. Несовместимость означает исходный конфликт между ORIGINAL владельцами в J или одно из четырёх противоположно-глубинных совпадений внутренних физических координат:

\[
x_1^\gamma=x_2^\eta,\quad x_2^\gamma=x_1^\eta,\quad
y_1^\gamma=y_2^\eta,\quad y_2^\gamma=y_1^\eta.
\]

Цель, ещё НЕ доказанная: B/M<3/4 во всех допустимых больших dyadic s. Нахождение конечного W(3,2) с B/M≥3/4 опровергло бы формулировку для *всех s*, но НЕ опровергло бы утверждение «для всех достаточно больших s» без бесконечного семейства. Отсутствие такого примера в эксперименте НЕ является доказательством.

## 2. Новая математическая all-h лемма: локализация риска в кликах от пяти

Пусть Q_uv — настоящий граф попарной несовместимости путей в данной endpoint-ячейке, \(\omega_{uv}\) — его точное кликовое число, \(M_{uv}=(\sum_{\gamma\in\Gamma_{uv}}p_\gamma)^2\). По взвешенному неравенству Моцкина—Штрауса, доказанному самостоятельно в #755,

\[
B_{uv}\le(1-1/\omega_{uv})M_{uv}.
\]

При \(M>0\) определим распределение массы по локальному кликовому числу:

\[
\lambda_k=M^{-1}\sum_{\omega_{uv}=k}M_{uv},\qquad
\lambda_k\ge0,\ \sum_k\lambda_k=1.
\]

Тогда для **любого порядка s, любых законных ORIGINAL f/g/Z/C** верно

\[
\boxed{B/M\le 1-\sum_k\lambda_k/k.}\tag{ADV-1}
\]

Из этого строго следуют два разных результата:

1. Если реальная конфигурация удовлетворяет **строгому** B/M>3/4, существует реальная endpoint-ячейка с положительной массой и \(\omega_{uv}\ge5\). Если \(\omega_{uv}\le4\) во всех ячейках, гарантировано только B/M≤3/4, а случай **равенства B/M=3/4 не исключён**: абстрактная 4-клика с равными положительными весами достигает его. Для доказательства строгого глобального B/M<3/4 требуется отдельный анализ граничных случаев равенства или положительная количественная компенсация.
2. Для конкретных ORIGINAL f/g достаточно проверить точное неравенство \(\sum_{uv}M_{uv}/\omega_{uv}>M/4\), чтобы доказать для **этой фиксированной конфигурации** B/M<3/4, не вычисляя индивидуальные плохие рёбра. Если критерий не проходит, это НЕ означает B/M≥3/4: неравенство Моцкина может быть неточным.

Математическое содержание нового шага — точный all-h кликово-взвешенный порог и необходимое сосредоточение опасной массы в локальных конфликтах с кликами размера ≥5, а не ещё одна необоснованная универсальная константа.

### Дополнительная all-h лемма: компенсация опасных ячеек безопасными

Обозначим долю ВСЕГО source-weighted endpoint-square M, приходящуюся на ячейки с истинной максимальной кликой не более трёх, через \(L=\sum_{k\le3}\lambda_k\), а долю с кликой не менее пяти — через \(H=\sum_{k\ge5}\lambda_k\). Прежняя самостоятельная all-h теорема #755 обеспечивает для любой ячейки \(\omega_{uv}\le Q_\star=4\,394\,000\). На ячейках с \(\omega\le3\) Motzkin даёт \(G_{uv}\ge M_{uv}/3\), на ячейках \(\omega=4\) — \(G_{uv}\ge M_{uv}/4\), на ячейках \(\omega\ge5\) — \(G_{uv}\ge M_{uv}/Q_\star\). Сложение без предположений независимости даёт НОВЫЙ all-h неравенство

\[
\boxed{
\frac GM\ge
\frac14+\frac{L}{12}
-\left(\frac14-\frac1{Q_\star}\right)H.
}
\tag{ADV-3}
\]

В частности, **достаточное** условие для строго \(B/M<3/4\) имеет явный вид

\[
\boxed{L>(3-12/Q_\star)H.}
\tag{ADV-4}
\]

Это неравенство НЕ утверждает, что ADV-4 автоматически верно при произвольных ORIGINAL f/g. Оно переводит часть открытой задачи в конкретный структурный баланс source-weighted endpoint-массы: «сколько весит множество ячеек с \(\omega\le3\) по сравнению с ячейками с \(\omega\ge5\)». Отдельно сохраняется более точный достаточный критерий \(\sum_k\lambda_k/k>1/4\) из ADV-2, который может сработать даже тогда, когда грубый ADV-4 не срабатывает. Проверка обоих точных рациональных неравенств включена в код для каждой выбранной оригинальной конфигурации.

## 3. Подлинный W(3,2) и полный класс физических меток

У настоящего W(3,2) по 15 именованных исходных точек и прямых, 45 ORIGINAL флагов, физический алфавит a=6 и ровно C(6,2)=15 разных физических пар. Поэтому любое допустимое отдельное глобально pair-injective исходное назначение **полно и биективно** на каждой стороне. Оно кодируется парой перестановок \(F,G\in S_{15}\).

В этом исследовательском поиске исходный CORE **полный** (все 45 ORIGINAL флагов, Z=∅), каждому флагу принадлежат ровно 2 реально существующие противоположные диагонали: всего ровно 90 различных исходно-владельческих физических рёбер. Выборы перестановок F,G могут быть любыми и коррелированными, но после фиксации карты они НЕ рандомизируются при вычислении вероятностей.

Программа самостоятельно восстанавливает геометрию из единственной разрешённой опорной fixture true original symplectic W32 (#748), затем J на настоящих точечных/прямолинейных пучках, весь реальный физический граф и все правильные направленные P3; при любой ошибке исходных назначений, собственности рёбер или J-проперности путь завершится отказом.

## 4. Двухступенчатый адверсариальный поиск: эвристика отдельно от доказательства

**Stage I — только эвристический отбор.** Фиксированный Python seed 230756, пять заранее объявленных baseline назначений, 320 детерминированных предложений, включая независимые случайные перестановки обеих сторон, локальные swap-мутации и откаты к сильным кандидатам. Кандидаты ранжируются по упрощённому degree-product proxy \(\widetilde p_\gamma=\prod_{i\in S_\gamma}(1+d_J(i))^{-1}\). Это корректная локальная нижняя оценка компоненты приоритетов по Harris, но она **НЕ РАВНА** настоящей совместной вероятности. Её B/M отношение — исключительно эвристический score, никогда не используется как сертификат научного результата.

**Stage II — точная независимая перепроверка.** Для каждого из shortlist лидеров и двух baseline полностью заново вычисляются все genuine ORIGINAL physical P3, исходные J и реальные источники физических рёбер. Каждому уникальному набору трёх владельцев приписывается точная приоритетная вероятность из шестичленного порядка-интеграла, рассчитанная арифметикой Fraction. Итоговый exact pγ равен этой вероятности, умноженной на точное значение двух раздельных typed cut 1/64. Без предположений о независимости путей суммируются все SAME-ENDPOINT пары с их точными рациональными произведениями.

Для каждой ячейки отдельно строится настоящий физический граф несовместимости, независимо вычисляется его полное кликовое число (новый branch-and-bound алгоритм, не импортированный из #755), точная оценка \(M_{uv}/\omega_{uv}\), кликовая гистограмма, доля M в ячейках с кликой ≥5, а также суммы конфликтов J/x/y (эти отдельные суммы могут перекрываться; не складываются как разбиение). Точные исходные полные перестановки F/G, все веса B,G,M, exact B/M и доказательные статусы сохраняются в JSON сертификат для воспроизведения.

## 4.1. Новый фактический ORIGINAL-контрпример к **поточечному**, но не глобальному \(3/4\)

Детерминированный полный эксперимент на настоящем W(3,2) с двумя ОТДЕЛЬНО глобально pair-injective фиксированными метками нашёл следующую воспроизводимую исходную пару перестановок, в порядке истинных именованных point/line индексов источника:

\[
F=[2,1,10,3,13,12,9,4,0,6,11,5,14,7,8],
\]

\[
G=[7,9,12,5,10,3,0,2,6,11,13,1,14,8,4].
\]

Они задают две законные биекции истинных 15 исходных точек/прямых на 15 физических пар алфавита [6], а не независимые случайные метки. В FULL CORE присутствуют все 45 оригинальных флагов и 90 физических диагоналей, ORIGINAL Z отсутствует. Полный source-first перебор даёт **1 378** правильных ориентированных физических P3, **5 466** упорядоченных SAME-ENDPOINT пар и точный общий результат

\[
\boxed{
(B/M)_{\rm whole\ W32}=
\frac{575861148421866450}{1128817197918722087}
\approx0.5101456192<3/4.
}
\tag{ADV-5}
\]

Это существенно выше полной lex baseline \(0.33233\), но **не опровергает общую глобальную** границу \(B/M<3/4\). Точное количество и доля массы ячеек с \(\omega\ge5\) дают

\[
H=\frac{277440244430073725}{1128817197918722087}
\approx0.2457796045.
\tag{ADV-6}
\]

Более важно, в той же подлинной ORIGINAL геометрии, при том же общем фиксированном F,G и одном общем селекторе, существует конкретная ячейка физических упорядоченных концов

\[
u=(0,2),\qquad v=(2,0),
\]

с **12** настоящими исходно-владельческими координатно-правильными направленными P3 и максимальной попарно-несовместимой кликой **8**. Для неё точное вычисление совместной source priority вероятности каждого трёхфлагового пути даёт

\[
\boxed{
B_{uv}/M_{uv}
=\frac{284477084}{355586449}
\approx0.8000222866>\frac34.
}
\tag{ADV-7}
\]

Это **настоящий контрпример** к предложению, что «в КАЖДОЙ физической endpoint-ячейке ORIGINAL источника при всех допустимых fixed f/g выполнено \(B_{uv}/M_{uv}<3/4\)». Здесь все 12 путей реальны, без клонирования, исходные J/физические внутренние координаты восстановлены заново, обе typed factor раскраски общие, а pγ вычислены строго рационально через исходные реальные приоритеты. Такой поточечный путь к глобальному B/M<3/4 **закрыт контрпримером**, но сама глобальная гипотеза осталась открытой. Более того, одно малое W32 не опровергает утверждение только для достаточно больших s.

Полный JSON сертификат сохраняет **каждый из 12** реальных физических P3 как четыре физических вершины и три оригинальных incidence-ID владельца с индивидуальной точной вероятностью pγ, **каждую** несовместимую неупорядоченную пару с источником J/x/y, точный вес B_uv и M_uv, все исходные отображения F,G, и проверку значения (ADV-7). Независимый тест реконструирует все физические рёбра, их ORIGINAL ID, все 12 вероятностей и заново суммирует локальный риск; не ограничивается сравнением напечатанных констант.

В полном эксперименте из 320 предложений было **316 уникальных** fixed F/G кандидатов (повторные перестановки при локальных мутациях и рестартах допустимы). Все 320 предложения детерминированны и воспроизводимы тем же seed, однако этот фиксированный бюджет не является исчерпывающим перебором \((15!)^2\) пространств.

**Scientific STOP:** 80% — локальный B_uv/M_uv в одной настоящей ячейке, а НЕ общий B/M, не нарушение all-h строгого root Branch A, не найденное бесконечное семейство и не новый ASET exponent.

## 5. Отдельные абстрактные контроля

Чисто графовая четвёрка равновесных несовместимых вершин имеет B/M=3/4; чисто графовая пятёрка — B/M=4/5>3/4. Это демонстрирует необходимость аккуратного строгого неравенства и кликовой структуры, но **не является** настоящим ORIGINAL symplectic source контрпримером.

Код отдельно может строить ORIGINAL named-Z удалённые CORE в конечном W32 для корректности владения физическими рёбрами. Такая конечная удалённая конфигурация не объявляется допустимой для асимптотического малого ограничения |Z|≤ρs⁴ на s=2, поскольку ρ крайне мало; основной адверсариальный поиск работает без удалений.
