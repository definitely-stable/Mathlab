# HYP-105 #230: доказанные локальные барьеры и точный индекс исходных типов

Статус исходной задачи: **OPEN_WITH_FORMAL_BLOCKER**.
Ограниченные теоремы ниже не доказывают ветви A/B и не являются
эквивалентным сокращением, требуемым полной ветвью C. Полный R2/R3 и
новый показатель ASET не заявляются. Связано с #230, #176 и #169;
эти задачи не закрываются.

Этот результат основан на EICE-003-H (#464), исходный SHA
`65f1acb45999bee44b73bfa69b479b3457eea088`. Исходная геометрия — настоящий
W(3,2^h), обе глобальные разметки инъективны в минимальный K_a.
Везде сохраняются исходные идентификаторы инцидентностей.

## 1. Полная локальная конструкция для всех h>=3

Для каждого s=2^h>=8 существуют полные глобальные разметки и выбранный
исходный matching из 2s+1 инцидентности, сохраняющий обе диагонали, с
одной средней инцидентностью, поддерживающей ровно

    C(s,2)^2 = (s^4-2s^3+s^2)/4

различных пятисемейств из четырёх чистых по концам, внутренне
заблокированных истинных GQ-путей. Все выбранные NB3 координатно
правильны; есть обе общие координатные двухцветные раскраски и нет
координатных вишен.

При s=8 независимо проверены 128 NB3, 784 пятисемейства и 1568
ориентированных квадратов. Но выбранный граф имеет только 4s+2 ребра и
минимальную положительную степень 1. Это опровергает o(s^4)-ёмкость,
выведенную из одних перечисленных локальных условий. Это **не**
контрпример к более сильной ёмкости для плотных высокостепенных G*.

Полное символьное доказательство:
[LOCAL-CAPACITY-BARRIER](HYP-105-ISSUE230-LOCAL-CAPACITY-BARRIER.ru.md).
Оракул: `research/hyp105_issue230_local_capacity_barrier.py`.

## 2. Нулевая локальная компенсация цикла и единственного якоря

Для всех s>=8 построен настоящий индуцированный 18-инцидентный
подграф исходной геометрии. Его метки продолжаются до полных глобальных
инъекций. В нём пять правильных P3 с одними концами и настоящим
единственным исходным якорем; все пять блокированы. Физических C6 —
десять, но все неправильны: пять имеют размерности 5/6, пять — 6/5.
Семисемейный счёт выбранного 18-источникового подграфа равен нулю.

Это точный фальсификатор локального переноса «несколько циклов плюс
якорь содержат принимаемую шестёрку». Подграф не имеет координатных
двухцветных раскрасок и высокой минимальной степени; полный глобальный
S его продолжения не вычислен.

Полное доказательство:
[LOCAL-CYCLE-BARRIER](HYP-105-ISSUE230-LOCAL-CYCLE-BARRIER.md).
Два независимых селектора и отдельная реализация GF(8):
`research/hyp105_issue230_local_cycle_pattern.py`,
`research/hyp105_issue230_local_cycle_barrier.py`.

## 3. Два ограничения геометрических конструкций контрпримера

Буквальное кодирование прямой парой настоящих исходных точек позволяет
представить не более

    [(s-1)a+a^2/(s+1)]/2 = O(s^(5/2)) = o(V)

различных прямых. Доказательство — точная спектральная оценка исходного
графа коллинеарности; двойственное утверждение также верно.

Аддитивные проектные пары Плюккера [u_i+u_j] в параболическом
квадратичном пространстве Q(4,s) требуют более a^2/100 исключительных
физических пар для s>=8. Для s>=32 хотя бы V/100 занятых исходных
меток должны быть исключениями. Исправление o(V) объектов этот шаблон
не спасает. Это не запрет произвольных коррелированных разметок.

Доказательства, точные константы и отдельный открытый аффинный шаблон:
[GEOMETRIC-DUAD-BARRIERS](HYP-105-ISSUE230-GEOMETRIC-DUAD-BARRIERS.md).
Два метода квадратичной/исходной геометрии проверяют все 15/85 плоскостей
при s=2/4; спектральная оценка проверена на всех 32768 подмножествах W32.

## 4. Полный исходный индекс 631+11032

Все 203^2=41209 пар разбиений шести именованных позиций проверены
двумя методами исходного леса: union-find и независимым DFS. В индекс
попали 11663 необходимых leafless-типа:

| Верхняя степень при независимых равномерных метках | Типов |
|---:|---:|
| 6 | 631 |
| 9/2 | 2740 |
| 3 | 4630 |
| 3/2 | 3180 |
| 0 | 482 |

Подведущих необходимых типов — 11032. Эти степени не являются
верхними оценками при коррелированных разметках. Один исходный тип
не определяет физическую проекцию или положительный GF(5)-вес.
Физические полиномы хранятся отдельно от исходных разбиений.

Индекс: `research/fixtures/hyp105_issue230_local_transfer/original_partitions.csv`.
Его SHA-256:
`9bdf2652ef0ce211c739c6b1dc39702c3656e984c821674a51372dd9cfc04b7a`.
Полиномы и точные отчёты лежат рядом. Генератор:
`research/hyp105_issue230_partition_index.py`.

Контрольные S/Q4 на одних и тех же разметках W32 воспроизведены:
lex 259/50, reverse 169/32, S68 68/9, S72 72/10. Полные семисемейные
векторы и принятые GF(5)-нижние числители сохранены в
`w32_same_map_results.json`. Они не являются полным R3.

## 5. Воспроизведение и оставшийся глобальный шаг

```sh
python -m unittest discover -s research -p 'test_hyp105_issue230_local_transfer_barriers.py' -v
python research/hyp105_issue230_local_capacity_barrier.py /tmp/issue230-capacity
python research/hyp105_issue230_local_cycle_barrier.py
python research/hyp105_issue230_geometric_duad_barriers.py
python research/hyp105_issue230_partition_index.py /tmp/issue230-partitions
```

Скрипты не зависят от приватных workspace-путей и не перезаписывают
замороженные данные. Конечные проверки фальсифицируют ошибки
реализации; all-h утверждения обоснованы отдельными доказательствами.
Первый локальный якорь проверяется исходными путями и независимо
симплектической ортогональностью. Второй цикловой фальсификатор имеет
собственный генератор GF(8). Два предшествующих независимых математических
аудита приняли именно ограниченные формулировки, сохранив исходную
теорему открытой; это проверка другими агентами, не внешнее рецензирование.

Для ветви A остаётся доказать глобальный контроль блокировки в плотном
G* с минимальной степенью Omega(s), либо перенос заблокированных
пятисемейств в принимаемые положительные шестиинцидентные множества
с O(s^2) истинных прообразов на шестёрку. Локальные примеры не
опровергают такой глобальный результат и не создают его.

Для ветви B необходимы явные полные f_s,g_s на бесконечной последовательности
h и строгая оценка всей выбранной суммы S_s=o(s^6). Ни одна ограниченная
геометрическая лемма выше не подменяет это условие.
