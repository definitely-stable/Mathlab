# INDEX-001 G2-B4-C1 — double-generation peak × query × update-liveness gate

**Frozen 2026-10-09;** issue [#183](https://github.com/definitely-stable/Mathlab/issues/183), parents #173/#126. Follows merged [G2-B4-C0](INDEX-001-G2-B4-C0-BOUNDED-SPACE-WAL.md) (PR #186) and [G2-B4-B](INDEX-001-G2-B4-B-PAGE-RECOURSE.md) (PR #182). **Model-specific mathematical result, not a universal dynamic-index lower bound or novel cell-probe theorem.** This document freezes assumptions and proofs before declaring any original G2 lower bound.

## G0 — quantified common model

A binary latest-write-wins range map has N>=3, N odd, cells [0,N). The initial state a=(0,1,0,1,...,0), with N alternating maximal runs. Every acknowledged update assigns the first cell only, alternately 1,0,1,0,...; each update **changes** the semantic state. Let b=(1,1,0,1,...,0). The data toggles between a and b forever in the requested liveness property, and all untouched cells keep their original values. N is restricted to |uvar(N)|=|uvar(N-1)|.

The only **admissible implementation class here** is the two-generation, one-level, append-all WAL of C0: an **immutable IXR1 canonical RLE** base snapshot, a variable-length append-only sequence of independently CRC-framed RW updates (no coalescing, prefix discards, elision, indexes or cold/hot indirection), and one persistent B-byte control page. A direct checkpoint after an update allocates a new complete canonical base **while the previous base, previous WAL and control page still exist**, then retires old regions. Direct checkpoint does not append the same update to WAL. No third history log, free in-memory lookup cache, or deferred rebuilding is allowed. The fixed class is not asserted to implement real atomicity or durability.

Each file/region is page-aligned separately, B>=4. Snapshot lengths:

- L=|uvar(N)|, S_a=8+2L+2N, S_b=S_a-2. All update frames are E=9 bytes, since l=0,r=1.
- p_a=ceil(S_a/B), p_b=ceil(S_b/B). For this gate demand p_a=p_b=p (the proof can be generalized, but this removes rounding distractions). The persistent control consumes one page. The other persistent auxiliary RAM is **M=0 bits** in the executable comparison. If M is nonzero, the budget adds gamma*ceil(M/8) bytes, but this does NOT grant alternate use of that RAM for indexing inside this restricted implementation.
- A state-dependent limit is C(f)=floor(alpha*S(f))+beta*B+gamma*ceil(M/8), alpha=a_num/a_den rational >=0, beta,gamma>=0 integers. Require **both** after-update steady bytes D<=C(f) and transient peak bytes P<=C(f), and worst-case integrity-UNVERIFIED point lookup page reads Q<=Qmax. Zero-cost transient decoding/workspace, unpriced CPU and unrealistic page atomicity remain open limits of the C0 reference model.
- After t consecutive append actions following a checkpoint: D=(p+1+ceil(9t/B))*B. Its untouched far-end lookup must scan the full log (forward scan without summaries), control page and base prefix, costing Q=1+q_base+ceil(9t/B) page probes. These are exact **for this parser**, not general probe lower bounds. q_base is the set of prefix pages touched when looking up cell N-1 in a or b.
- A direct checkpoint into either target has **P>= (p_old+p_new+1)*B**, even with an empty old log, since old and new complete bases overlap plus control. This is an *invariant of the declared two-generation layout*, not a theorem that all crash-safe systems double-buffer.

## G1 — restricted non-liveness theorem (proof)

**Theorem C1.** Fix odd N with stable varint width, p_a=p_b=p. If the initial control+base fits the current budget, yet

    (2p+1)*B > max(C(a),C(b)),

then the specified immutable-base append-all implementation **cannot serve infinitely many acknowledged effective hot-bit toggles** under finite after-update space cap and finite read cap Qmax (indeed the space cap alone suffices). In particular, no schedule of APPEND or DIRECT_CHECKPOINT actions can satisfy those constraints for an infinite prefix.

*Proof.* Every direct checkpoint must simultaneously retain old base (one of a,b), allocate new base (the other state), and retain the control page; both bases occupy p pages. Its peak is at least (2p+1)B, exceeding the allowed cap in either state. Thus no checkpoint can be selected, including the very first operation. Every acknowledged effective update must consequently append a non-elided CRC frame of exactly 9 bytes, so after t steps D(t)=(p+1+ceil(9t/B))*B, which increases without bound as t→∞, whereas max(C(a),C(b)) is finite for this N. Hence eventually D(t)>C(f_t), a contradiction. Additionally the untouched-position query incurs Q(t)=1+q_base+ceil(9t/B), also unbounded. All statements quantify **this restricted class** and explicit service, not arbitrary dynamic succinct representations. □

**Asymptotic corollary.** Fix B, beta, gamma, alpha<2 and M=o(N) persistent bytes/bits (more precisely gamma*ceil(M/8)=o(N)). Along odd N avoiding the varint crossings, S_a,S_b=2N+O(log N), and the two-generation minimum peak is S_a+S_b+O(B), whereas max cap = alpha*(2N+O(log N)) + O(B)+o(N). For all sufficiently large N the peak inequality holds. This does **not** prove impossibility of all state-adaptive compressed indexes; it shows that a hard *peak* compressed-space factor strictly below two is incompatible with immutable overlapping full-base replacement on this adversarial family.

**Quantitative necessary checkpoint/read/write bound.** If the two possible base versions have an equal untouched-position prefix cost q_base and the implementation remains admissible with Qmax>=1+q_base, let T=floor(B*(Qmax-1-q_base)/9). No epoch can contain T+1 consecutive appends; in any U acknowledged operations, any feasible schedule therefore has at least floor(U/(T+1)) direct checkpoints, costing at least floor(U/(T+1))*(min(p_a,p_b)+1)*B modeled bytes for fresh base pages+control, ignoring the additional append costs. If Qmax<1+q_base, even a checkpoint-only reader violates this model's query cap. This is only a necessary bound; peak constraints may make the schedule **infeasible**.

**Concrete exact certificate (all costs bytes/pages, not real I/O):**

- N=129, B=32, alpha=7/4, beta=2, gamma*M=0. Base canonical S_a=270 and S_b=268 bytes. Both require p=9 pages. Complete old/new/control checkpoint peak is at least (9+9+1)*32=608 bytes even with no WAL. Caps are C(a)=536, C(b)=533 bytes. No checkpoint is permitted.
- An untouched far-end lookup of either complete base takes q_base=9 pages. Control adds 1; a t-frame WAL adds ceil(9t/32) pages. With Qmax=12, t=7 still gives Q=12, but the **eighth update reaches Q=13** and cannot be acknowledged by either permitted action, despite still fitting steady space. A no-query-cap (Qmax=100) control reaches a **steady-space violation at update 22**: 22 frames consume 7 pages, giving D=(9+1+7)*32=544 > C(a)=536; t=21 consumes 6 log pages and stays admissible. Both sequences use genuine, effective toggles with exactly one changed cell, not semantically redundant frames.
- For the Qmax=12 variant T=floor((12-1-9)*32/9)=7. Any viable U-step schedule (if peak allowed) would require at least floor(U/8) full-base checkpoints; none is viable under the frozen peak cap above.

The counterexample is **not evidence for a universal alpha>=2 requirement**: in-place packed overwrites, raw arrays, fixed slots, frame coalescing, in-RAM hot-cell indexes, constant-time alternate coding and more advanced generation models are outside the theorem and may satisfy other bounds.

## G2 — executable gates, comparison to prior art, next slice

1. The independent arithmetic certificate computes all bits and exact varint sizes from scratch; the C0 WAL implementation independently serializes and decodes every frame, replays latest-write-wins, prices pages and point-query prefixes. The two paths must agree at every t.
2. An exact finite Bellman oracle selects **APPEND** or **DIRECT_CHECKPOINT** after each update and filters both steady/peak state budgets and point-read cap. Verify against completely separate 2^U action-schedule enumeration for small traces, varying budgets and Q. All structural state keys preserve full base and WAL bytes; no free garbage collection of partially live state.
3. Quantitative conditions checked at varint boundary-adjacent N, different B, effective alternating hot toggles, and parameter failures. Hosted GitHub CI runs both global unittest discovery and a standalone deterministic certificate. Source/paper novelty check before promoting beyond restricted theorem.
4. **Prior-art boundary:** The double-generation peak-space obstacle is a special case of copy-on-write and space amplification; the append/query bound belongs to the established compaction / online dynamization family (canonical LIT-098, LIT-182/185/186). Dynamic succinct structures (LIT-177/179/180/181, LIT-212/213), RASK LIT-175 and classical cell-probe bounds prevent any unqualified transfer to arbitrary indexed representations. This is evidence with sharp model quantifiers, **not claimed as a newly discovered universal theorem**.
